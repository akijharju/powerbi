# Power BI -portfolio

Tämä repositorio sisältää Power BI -kurssilla toteuttamani kolmiosaisen harjoitustyökokonaisuuden.

Raporteissa painopiste on ollut Power BI:n teknisten ominaisuuksien, tietomallinnuksen ja analytiikan toteuttamisessa. Visuaalinen viimeistely on tästä syystä pidetty tarkoituksella yksinkertaisena.

## Osat 1–2: Myynnin analysointi

Myyntiaineistoon perustuvassa raportissa toteutin muun muassa:

* aineiston käsittelyä Power Querylla
* tietomallinnusta ja kalenteritaulun
* DAX-mittareita ja aikasidonnaisia laskentoja
* Calculation Groupin
* dynaamisen kenttäparametrin
* drill-through-sivun
* erilaisia visualisointeja ja suodattimia

Raporttitiedosto: `Company_X_Sales_Analysis.pbix`

## Osa 3: Euribor-korkojen analysointi

Raportti käsittelee vuosien 2024–2025 Euribor-korkoja. Toteutuksessa käytin Power BI Desktopin lisäksi Power BI Serviceä.

Työssä toteutin muun muassa:

* CSV-aineiston käsittelyn
* Dataflow Gen1 -tietovuon
* OneDriveen tallennetun tietolähteen
* aineiston ajastetun päivittämisen
* kalenteritaulun ja tietomallin
* korkojen kehitystä kuvaavia visualisointeja

Raporttitiedosto: `Euribor_Analysis.pbix`

## Käytetyt työkalut ja tekniikat

* Power BI Desktop
* Power BI Service
* Power Query
* DAX
* Dataflow Gen1
* OneDrive
* tietomallinnus
* datan visualisointi

Raportit on toteutettu osana Power BI -opintojaksoa. Repositoriossa olevat PBIX-tiedostot voi avata Power BI Desktopilla.
